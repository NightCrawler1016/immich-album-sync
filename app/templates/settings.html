Backup & Restore

Save all sync jobs and notification settings to a file you can restore later — on this install, a rebuilt container, or a newer version. Your login and the container's environment variables are not included.

With a passphrase, the API keys and webhook URLs are included, encrypted with it — you need the same passphrase to restore, and it can't be recovered. Without one, they are left out and you re-enter the keys (and any custom webhook URLs) after restoring.

Restoring replaces all current sync jobs (and their run history) and the notification settings. It can't be undone — download a backup of the current setup first if you might want it back.
